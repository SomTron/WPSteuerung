# Entwicklungs- und CI-Abhaengigkeiten.
#
#   pip install -r requirements-dev.txt
#
# Enthaelt zunaechst die Laufzeit (requirements.txt) und legt dann die
# Werkzeuge obendrauf. Der Pi braucht diese Datei NICHT - dort laeuft
#   pip install -r requirements-pi.txt
# (nur Laufzeit + Hardware).
#
# WARUM GETRENNT (aufgeraeumt 11.11.2026): pytest, pytest-asyncio, ruff und
# mypy standen vorher in requirements.txt - und requirements-pi.txt zog sie
# ueber "-r requirements.txt" damit auf den Pi. Auf einem 512-MB-Geraet ist
# das Grundlast (ruff und mypy sind je zweistellig in MB), ohne im Betrieb je
# verwendet zu werden. Die CI installierte sie mit, obwohl sie sie braucht -
# dieser Weg bleibt, aber jetzt ohne den Pi zu belasten.
#
# PINNING (Stand 11.11.2026): gleiche Regel wie requirements.txt - exakte
# Versionen, damit ein Build reproduzierbar ist. Die Pins entsprechen dem
# Stand, gegen den die Tests laufen (lokal verifiziert).
-r requirements.txt
